# UI/UX 검토 및 개선

## 검토 자료

`AI기반 데이터분석 솔루션구축 UI_v02_20260915_복호화.pptx`의 8개 슬라이드와 포함된 화면 이미지 8개를 검토했습니다. PPTX에는 홈, 분석 설정, 데이터 불러오기, 데이터 조회, 연결 설정과 각각의 대화형 입력 화면이 있습니다. 문서 내 의견은 설계 참고 자료로 사용했습니다. 실제 사용자 조사나 운영 데이터로 검증된 결론은 아닙니다.

## 개선 사항

| 원본에서 관찰한 문제 | 개선 방향 | 구현 |
| --- | --- | --- |
| 분석 5단계와 데이터 준비 6단계가 동시에 노출됨 | 단계 정보의 우선순위를 정하고 한 화면 내 진행 순서를 단순화 | 상단 5단계, 데이터 선택·연결·검증은 데이터 준비 안에서 처리 |
| 전역 메뉴와 문맥 도구가 모두 왼쪽에 배치되어 역할이 바뀜 | 전역 탐색과 분석 편집을 구분 | 고정 사이드바와 별도 분석 생성 다이얼로그 |
| AI 입력/직접 입력 화면 전환과 동일 작업 맥락이 불분명 | 동일 데이터 상태에서 모드만 전환 | 선택 데이터 유지, AI 가이드/직접 설정 토글 |
| 추천의 이유와 적용 범위가 흩어져 있음 | 제안과 적용 행동을 붙이고 자동 실행을 피함 | 추천 데이터·키·연결 방식 표시 및 적용 버튼 |
| 데이터 마트/파일 업로드가 메뉴인지 화면 내 작업인지 미정 | 모두 데이터 소스라는 동일 개념으로 구성 | 준비 화면 내 데이터 마트/CSV 업로드 탭 |
| 첫 화면에 알림, 바로가기, 분석 시작의 우선순위가 비슷함 | 시작 행동을 주목점으로 만들고 업무 복귀를 지원 | AI 질문 영역, 새 분석 버튼, 최근 분석, 추천·소식 순서 |
| 작은 글자와 밀집된 패널 | 정보 묶음, 여백, 대비, 일관된 타이포그래피 | 카드 기반 레이아웃, 확대된 본문 및 보조 텍스트, 반응형 배치 |
| 저장/다음 버튼만으로 준비 상태가 명확하지 않음 | 필수 조건과 오류를 해당 작업 안에서 안내 | 이름 필수 검사, 데이터 선택 검사, 검증 완료 후 다음 단계 |
| 차트 데이터가 실제인지 구분하기 어려움 | 데이터 출처와 기능 범위를 분명히 표시 | 샘플 환경, 예시 AI 답변·인사이트, 고정 차트 안내 |

## 시각 설계

기업 분석 도구의 신뢰감을 유지하면서 밝은 인디고와 라벤더를 사용했습니다. 전역 내비게이션은 흰색, 작업 영역은 옅은 회색, AI 진입 영역은 라벤더로 구분합니다. 섹션 제목·주요 행동·내용·메타데이터 순으로 위계를 두며 아이콘은 Lucide로 통일했습니다. 실제 LS MnM 로고나 브랜드 가이드를 받지 않아 텍스트 워크스페이스명과 독자적인 MnM Insight 마크를 사용합니다.

모바일에서는 사이드바를 접고 카드/데이터 패널을 세로로 배치합니다. 표는 내부 가로 스크롤을 허용합니다. 키보드 포커스, 본문 바로가기, 아이콘 버튼 이름, 다이얼로그 Escape 닫기와 포커스 복원을 제공합니다. 전체 WCAG 적합성 인증이나 실제 보조공학 사용자 테스트를 수행한 것은 아닙니다.

## 후속 제품 구현에 필요한 것

1. 인증과 역할별 데이터/리포트 접근 정책, 실제 사내 데이터 스키마
2. 쿼리 실행 서비스, 대용량 파일 처리 및 실제 JOIN·형식/품질 검증
3. AI 제안 API, 근거·불확실성 표시, 쿼리 확인·승인과 실행 취소
4. 차트의 실제 집계 데이터 바인딩, 축/단위/필터 정의
5. 서버 저장 및 임시저장 재개, 공동 공유/게시 범위와 이력
6. 현업 사용자 대상 과업 테스트: 첫 분석 성공률, 데이터 준비 시간, 오류 복구

이 프로토타입은 위 후속 기능을 갖춘 운영 솔루션이 아니라 개선된 화면과 주요 인터랙션을 검토하기 위한 구현입니다.
