# 검증 기록

## 2026-10-06 로컬 Windows UI/UX 개선 검증

- 프로덕션 빌드와 TypeScript 검사 통과.
- 기존 테스트 9개 통과: 분석 생성·즐겨찾기·로컬 저장·CSV 업로드와 다운로드·6단계 데이터 준비·모바일 조작·경로 이동.
- 추가 UX 테스트 2개 통과: 검색 초기화, 검색어 앞뒤 공백, 이름 누락 시 입력 포커스, 375/768/1440px 및 812×375 가로 화면의 페이지 가로 넘침 검사.
- 모션 감소 설정에서 홈 화면을 캡처하고 데스크톱·작은 모바일 캡처를 시각 검토했습니다.
- 기존 서버와 충돌하지 않도록 `E2E_PORT=3101`을 사용했습니다. Windows Chrome 경로는 `CHROMIUM_PATH`로 지정했습니다.

이 검증은 Chromium 기반입니다. Safari·Firefox, 전체 WCAG 적합성, 실제 사용자 과업 테스트는 수행하지 않았습니다.

2026-10-06, 현재 클라우드 환경에서 수행했습니다.

- Node.js 24.19.0 / npm 11.9.0 / Next.js 16.3.8 / React 19.3.0
- `npm run build`: 성공. `/`, `/analyses`, `/data-library`, `/reports`, `/favorites`, `/settings` 독립 페이지 정적 생성
- `npm run typecheck`: 성공
- `npm run test:e2e`: **9개 통과**, 실패/스킵 없음 (브라우저 시나리오 6개, 데이터 처리 검증 3개)

## 검증한 동작

1. 홈, 즐겨찾기 선택/해제와 새로고침 복원, 이름 검색과 필터 초기화
2. 준비 6단계, 이름/저장 조건 검사, 체크박스 라벨 클릭과 Space 키 조작
3. LEFT JOIN 결과 7행 / INNER JOIN 결과 6행, 다중 키 매칭과 비매칭
4. 결측·중복 제거 후 5행, 달성률 계산열, 전기동 생산수량 집계 2,468
5. 결과 품질 검증, 데이터셋 저장, 분석 게시, 새로고침 후 라이브러리에서 처리 결과 확인
6. 잘못된 CSV 차단, UTF-8 BOM·따옴표 내 쉼표/줄바꿈·CRLF·이스케이프 처리 및 숫자 타입 추론
7. CSV 수량 200 이상 필터와 내림차순 정렬, 실제 결과 다운로드 내용 확인, 최근 저장 데이터 재사용
8. 빈 필터 결과와 잘못된 계산열/숫자 대체값 검사, 집계 후에도 숫자 형식 오류 유지
9. 소스별 데이터 검색 및 실제 샘플 CSV 다운로드
10. 390px 모바일 메뉴·조회·전처리·검증·Escape 닫기·포커스 복원, 페이지 가로 넘침과 JavaScript 오류 없음
11. 다섯 메뉴 경로의 직접 접속·새로고침·활성 메뉴, URL 변경과 브라우저 뒤로/앞으로 이동

데스크톱·모바일 화면 캡처로 확대된 글자와 배치를 확인했습니다. 데스크톱 콘텐츠 설명은 기존 12px에서 14px로 확대되었습니다. 단계 이동 시 본문 스크롤이 0으로 복원되고 새 단계 제목에 포커스가 이동하는 것도 확인했습니다. 긴 작업 내용 안에서도 분석 이동 버튼은 하단에 유지됩니다.

기본 환경에서는 잠금 파일 기반 `npm ci`, 개발 서버 시작과 홈 HTTP 200도 검증했습니다. 이후 제품 수정은 위 프로덕션 빌드와 현재 테스트로 확인했습니다.

## 한계

실제 AI 응답 품질, 사내 데이터 마트, 서버 쿼리, 인증, 다중 소스 연속 조인, 다른 사용자와의 공유는 구현·검증 범위 밖입니다. 데이터 준비 연산은 로컬에서 실제로 수행하지만 차트와 인사이트는 여전히 고정 예시이며 준비 결과에 자동 연결되지 않습니다. 준비 데이터셋은 현재 브라우저에 저장하고, 분석 임시저장은 메타데이터만 보관하므로 전체 편집 단계 재개는 지원하지 않습니다.
