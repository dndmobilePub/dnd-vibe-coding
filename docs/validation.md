# 검증 기록

2026-10-06, 현재 클라우드 환경에서 수행했습니다.

- Node.js 24.19.0 / npm 11.9.0
- Next.js 16.3.8 / React 19.3.0 / TypeScript
- `npm run build`: 프로덕션 빌드 성공, 홈 및 아이콘 정적 생성
- `npm run typecheck`: 성공
- `npm ci --cache /workspace/.npm-cache --no-audit --no-fund`: 잠금 파일 기반 재설치 성공
- `npm run dev`: 개발 서버 시작, 홈 HTTP 200, 브라우저 오류 없음
- `npm run test:e2e`: Chromium에서 **5개 테스트 통과**, 실패/스킵 없음
  - 홈 표시, 즐겨찾기와 새로고침 복원, 검색 및 필터 초기화
  - 이름 필수 검사, 추천 데이터 선택, 검증 전 진행 방지, 차트 선택과 게시/복원
  - 잘못된 CSV 차단, UTF-8 BOM/따옴표 안 쉼표/CRLF 처리, 미리보기
  - 데이터 검색 및 CSV 다운로드 이벤트
  - 390px 모바일 메뉴, 가로 넘침 없음, Escape 닫기와 포커스 복원, JS 오류 없음
- 데스크톱/모바일 화면 캡처로 카드 배치와 글자 크기를 검토
- 1440px/390px 최종 캡처에서 페이지 가로 넘침 및 JavaScript 오류 없음

검증 과정에서 테스트가 Next.js의 기본 route announcer를 오류 알림으로 함께 선택하는 문제와 파일명+행 수를 하나의 요소로 읽는 선택자 문제를 수정했습니다. 재빌드 전 서버를 재사용해 이전 리소스를 요청한 실행은 중단하고 새 서버에서 전체 테스트를 다시 수행했습니다.

실제 AI 응답 품질, 실제 데이터 JOIN/집계, 인증, 다른 사용자와의 공유는 구현 범위 밖이며 검증하지 않았습니다. 새 클라우드 작업의 스냅샷 복원과 환경 게시 또한 별도입니다.
