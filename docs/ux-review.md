# UI/UX 검토 및 개선

## 검토 자료

`AI기반 데이터분석 솔루션구축 UI_v02_20260915_복호화.pptx`의 8개 슬라이드와 포함된 화면 이미지 8개를 검토했습니다. PPTX에는 홈, 분석 설정, 데이터 불러오기, 데이터 조회, 연결 설정과 각각의 대화형 입력 화면이 있습니다. 문서 내 의견은 설계 참고 자료로 사용했습니다. 실제 사용자 조사나 운영 데이터로 검증된 결론은 아닙니다.

## 개선 사항

| 원본에서 관찰한 문제 | 개선 방향 | 구현 |
| --- | --- | --- |
| 분석 5단계와 데이터 준비 6단계가 동시에 노출됨 | 단계 정보의 우선순위를 정하고 한 화면 내 진행 순서를 단순화 | 분석 5단계 아래에 데이터 준비 6단계를 복원하고 별도 진행 표시·단계별 도구 제공 |
| 전역 메뉴와 문맥 도구가 모두 왼쪽에 배치되어 역할이 바뀜 | 전역 탐색과 분석 편집을 구분 | 독립 URL이 있는 전역 사이드바와 별도 분석 생성 다이얼로그, 단계에 맞는 도구 패널 |
| AI 입력/직접 입력 화면 전환과 동일 작업 맥락이 불분명 | 동일 데이터 상태에서 모드만 전환 | 선택 데이터 유지, AI 가이드/직접 설정 토글 |
| 추천의 이유와 적용 범위가 흩어져 있음 | 제안과 적용 행동을 붙이고 자동 실행을 피함 | 추천 데이터·키·연결 방식 표시 및 적용 버튼 |
| 데이터 마트/파일 업로드가 메뉴인지 화면 내 작업인지 미정 | 모두 데이터 소스라는 동일 개념으로 구성 | 준비 화면 내 데이터 마트/CSV 업로드 탭 |
| 첫 화면에 알림, 바로가기, 분석 시작의 우선순위가 비슷함 | 시작 행동을 주목점으로 만들고 업무 복귀를 지원 | AI 질문 영역, 새 분석 버튼, 최근 분석, 추천·소식 순서 |
| 작은 글자와 밀집된 패널 | 정보 묶음, 여백, 대비, 일관된 타이포그래피 | 카드 기반 레이아웃, 확대된 본문 및 보조 텍스트, 반응형 배치 |
| 저장/다음 버튼만으로 준비 상태가 명확하지 않음 | 필수 조건과 오류를 해당 작업 안에서 안내 | 이름 필수 검사, 데이터 선택·컬럼·연결 키·결과 품질·이름 검사, 검증과 데이터셋 저장 후 차트 단계 |
| 차트 데이터가 실제인지 구분하기 어려움 | 데이터 출처와 기능 범위를 분명히 표시 | 샘플 환경, 예시 AI 답변·인사이트, 고정 차트 안내 |

## 시각 설계

기업 분석 도구의 신뢰감을 유지하면서 블루와 스카이블루를 사용했습니다. 주요 행동은 블루(#1769D3), 보조 강조는 스카이블루(#207CA8)로 통일하고, 전역 내비게이션은 흰색, 작업 영역은 옅은 회색, AI 진입 영역은 옅은 블루로 구분합니다. 섹션 제목·주요 행동·내용·메타데이터 순으로 위계를 두며 아이콘은 Lucide로 통일했습니다. 실제 LS MnM 로고나 브랜드 가이드를 받지 않아 텍스트 워크스페이스명과 독자적인 MnM Insight 마크를 사용합니다.

모바일에서는 사이드바를 접고 카드/데이터 패널을 세로로 배치합니다. 표는 내부 가로 스크롤을 허용합니다. 키보드 포커스, 본문 바로가기, 아이콘 버튼 이름, 다이얼로그 Escape 닫기와 포커스 복원을 제공합니다. 전체 WCAG 적합성 인증이나 실제 보조공학 사용자 테스트를 수행한 것은 아닙니다.

## 데이터 준비 기능 재점검

슬라이드 3·5·7의 상단에는 **불러오기 → 조회 → 연결 → 전처리 → 결과 보기 → 데이터셋 저장**의 6단계가 명시되어 있습니다. 초기 프로토타입의 단일 준비 화면은 이 기능을 충분히 담지 못해 다음과 같이 보완했습니다.

| 기획 화면의 기능 | 이번 구현 | 동작 범위 |
| --- | --- | --- |
| 데이터 마트/로컬 파일/최근 데이터, 검색, 선택 목록 | 네 개 샘플 소스 검색, CSV 선택·드롭, 선택 해제, 최근 저장 결과 | 실제 로컬 행·컬럼으로 처리 |
| 메인 데이터 조회, 컬럼 선택, 필터, 정렬, 품질 요약 | 주 데이터 변경, 컬럼 체크박스, 여러 AND 필터, 숫자·문자 정렬, 페이지 이동 | 실제 미리보기 변경 |
| 원천 데이터, 조인, 파라미터, 키 추가 | 소스-조인-소스 연결 화면, LEFT/INNER, 주·연결 데이터 선택, 다중 키 | 두 소스 결합, 빈 키는 미매칭 |
| 전처리·필터·집계·계산열 | 결측 제외/대체, 중복 제거, 달성률 계산열, 그룹별 합계 | 행·열이 실제로 변경됨 |
| 결과 보기와 품질 확인 | 결과 표, 결측 셀·중복·숫자 오류 집계 및 검증 | 비어 있는 결과·숫자 오류는 저장 차단 |
| 데이터셋 저장 | 이름 입력, 브라우저 저장, 라이브러리 조회, CSV 다운로드, 최근 데이터 재사용 | 현재 브라우저 내 영속 저장 |
| 직접 입력/AI 가이드 | 작업 설정을 유지하는 모드 전환, 단계별 가이드와 추천 적용 | 안내는 예시, 실제 AI 연결 없음 |

결측과 중복은 업무상 의도된 값일 수 있으므로 경고를 확인한 뒤 저장할 수 있습니다. 임의 행 선택을 통한 부분 추출, 드래그로 수정하는 자유로운 ETL 그래프, 줌/팬, 무제한 다중 소스 조인, 실제 AI 쿼리 생성은 후속 범위입니다. 현재 차트·인사이트는 샘플이며 준비 결과에 자동 바인딩되지 않습니다.

## 경로와 읽기 개선

나의 분석 `/analyses`, 데이터 라이브러리 `/data-library`, 공유 리포트 `/reports`, 즐겨찾기 `/favorites`, 설정 `/settings`를 각각 App Router 페이지로 분리했습니다. 제목·활성 메뉴·URL이 맞으며 직접 접속, 새로고침, 브라우저 뒤로/앞으로 이동을 지원합니다. 콘텐츠 본문·보조 글자·표·버튼은 기존 대비 2px 확대하고 주요 화면 타이틀(h1) 크기는 유지했습니다. 새 데이터 준비 화면은 본문 12~13px, 섹션 제목 14~19px을 사용합니다.

## 후속 제품 구현에 필요한 것

1. 인증과 역할별 데이터/리포트 접근 정책, 실제 사내 데이터 스키마
2. 서버 쿼리 실행 서비스, 대용량 처리, 다중 소스 연속 조인, 더 풍부한 스키마·품질 검증 (두 소스 JOIN과 기본 품질 검사는 로컬 구현됨)
3. AI 제안 API, 근거·불확실성 표시, 쿼리 확인·승인과 실행 취소
4. 차트의 실제 집계 데이터 바인딩, 축/단위/필터 정의
5. 서버 저장 및 임시저장 재개, 공동 공유/게시 범위와 이력
6. 현업 사용자 대상 과업 테스트: 첫 분석 성공률, 데이터 준비 시간, 오류 복구

이 프로토타입은 위 후속 기능을 갖춘 운영 솔루션이 아니라 개선된 화면과 주요 인터랙션을 검토하기 위한 구현입니다.
